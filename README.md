# Conway's Game of Life

Реализация классического клеточного автомата «Жизнь» Конвея. Программа визуализирует процесс эволюции системы на двумерной сетке, демонстрируя возникновение сложных паттернов на основе простых правил выживания и смерти клеток.

### Запуск

Для работы требуется Python 3.x и библиотека `pygame`.

```bash
# Установка зависимостей
pip install pygame

# Запуск симуляции
python main.py
```

### Пример

Программа отображает сетку, где живые клетки (белые) и пустые пространства (черные) взаимодействуют согласно правилам:
- Клетка с 2 или 3 соседями остается живой.
- Клетка с <2 или >3 соседями погибает.
- Мертвая клетка с ровно 3 соседями «рождается».

### Тесты
