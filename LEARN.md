# LEARN.md

## 1. Что сделали
Реализовали симулятор «Жизнь» Конвея на Python с использованием Pygame для визуализации. Проект состоит из нескольких модулей:
- `simulation.py`: Логика симуляции, включая правила обновления клеток.
- `visualization.py`: Визуализация сетки с помощью Pygame.
- `main.py`: Точка входа, объединяющая логику и визуализацию.
- `config.py`: Конфигурационные параметры (размер сетки, скорость и т.д.).

## 2. Что разобрать (концепции)
- **Клеточный автомат**: Основные принципы и правила Конвея.
- **Двумерные массивы**: Работа с сеткой и обновление состояний.
- **Pygame**: Основы работы с графикой и событиями.
- **Модульность**: Организация кода на отдельные модули.
